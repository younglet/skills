# 实战经验（MP2 / MP3 课件改版沉淀）

> 这份文档记录"把 24 讲课件从初稿改成可交付成品"的全过程里，**踩过的坑、定下的规则和阈值**。
> 拿到新项目时先读这份，能省掉一大半返工。

---

## 一、最终成品形态

- `MP2_PPT.pptx` 519 张 / 12 节；`MP3_PPT.pptx` 475 张 / 12 节。
- 每讲结构：

```
封面
复习：上节要点回顾          ← 问答成对；答案逐条淡入
代码回顾：<上一讲核心脚本>   ← 螺旋复习
课程引入
知识点…（概念页 → 原理/特点 → 应用）
模块页（若有）：模块介绍+硬件引脚 / 初始化参数 / 核心属性或方法 / 使用示例
编程任务…                   ← 每个任务后面紧跟它的代码页
小结与拓展
```

- 代码页：**标题只说功能**，页脚写"对应环节 ｜ 源文件"。

## 二、改过的几类问题（按主题）

| 主题 | 具体动作 |
| --- | --- |
| **教材式重构** | 每个关键概念先有"知识点介绍页"，再讲原理/特点/应用；不直接给结论 |
| **概念拆页** | 把揉在一页的两件事拆开（如 H 桥"逻辑线路"vs"功率驱动"、OLED vs SSD1306 驱动芯片、接口 vs JSON） |
| **纠错** | H 桥驱动原理、P7"后退同速反向"、接线表 TX/RX 接反、命令码编号、`STA/AP` 笔误等 |
| **前向引用** | 没讲过的词先用 → 移到该讲之后再出现（路由参数、peer、last_cmd、大端序…） |
| **命名统一** | NovaEyes/`RoboEyes`/`eyes`、`go_backward` vs `backward`、`ST A/AP` |
| **全量体检** | 页码连续性、emoji、行首标点、跨讲重复表、关键引脚一致性 |
| **代码入课件** | `inject_codes.py` + `place_codes.py` |
| **复习页** | 改成"教案问答 + 成对呈现 + 答案动画" |
| **配图** | 需求清单 → 外部生图 → `attach_images.py` 回填 |
| **去噪** | 去 emoji、去面向老师的元叙述、去"代码清单"页 |

## 三、踩过的坑（每条都真实发生过）

1. **HTML 标签的尖括号被剥掉**
   PPT 源里出现 `h1 LED 控制面板 /h1`、`!DOCTYPE html`。
   根因：中间处理环节把 `<...>` 删了。**修复**：对照原教案补回 `<h1>…</h1>`、`<div id="board"></div>` 等。

2. **`第 _ 页` 占位符导致重编号失效**
   插入新页时用 `第 _ 页` 占位，而重编号正则写的是 `^第\s*\d+\s*页`（不含 `_`）→ 新页没被当页分隔符，页码出现跳号。
   **修复**：占位先替换成 `第 0 页`，或重编号正则改成 `^第\s*[_\d]+\s*页`。

3. **PowerPoint 占用导致写入失败**
   脚本会 `PermissionError` → 自动另存 `<名>_fixed.pptx`。
   **处理**：让用户关闭 PowerPoint 后覆盖；顺手在 `.gitignore` 加 `~$*`（Office 锁文件）。

4. **目录互相污染导致"节数翻倍"**
   备份还原时把 `_bak` 里的两门课文件一起拷进了 `MP2_PPT/` 与 `MP3_PPT/`，`build_ppt.py` 按 glob 数量分节 → 变成 24 节。
   **修复**：清理目录；`build_ppt.py` 的分节数必须等于课程讲数，纳入自查清单。

5. **代码硬切两页，读不懂**
   一开始按 32 行切，可读性差。**规则改为**：每页 ≤20 行，**按逻辑断点切**（空行 / `def` / `class` / `@` / 注释分段），**逻辑优先于均衡**（宁可 14/8，不把函数劈开）。

6. **顶部注释头被搬进课件**
   每页开头都是 `# 文件名:` `# 功能:` `# 说明:`，占地方。
   **修复**：`readlines()` 里统一剥掉文件顶部注释块。

7. **复习页的答案"被挪到页尾"**
   生成器把 `答：` 行当成"动画内容"，且动画被合并到一个文本框并追加到末尾 → 页面变成"先一排问、后一排答"。
   **修复**：复习页必须**保持原序**；再进一步改成**段落级动画**（`<p:pRg st="i" end="i"/>`），实现"点一下出一条答案"。
   注意：`collect()` 里只有 `✅` 开头才算 `ans`，`答：` 是普通文本 —— 判断"哪条是答案"要用**紧跟问题之后**这条规则。

8. **答案压成一行把内容砍没了**
   为追求"一行"把 155 字的答案截成 40 字，命名规律、H 桥四种状态全丢。
   **修复**：答案**保留完整**（≤200 字，约 4 行），靠**分页**容纳；精简只在超限时做，且**括号安全**（不切开 `foo()`、`（…）`）。

9. **封面背景图尺寸算错**
   按 13.333×7.5 英寸铺图，实际模板是 **10×5.625 英寸** → 图片溢出。
   **修复**：一律用 `prs.slide_width/height`，不要写死。

10. **代码里的 emoji 进了幻灯片**
    源码注释/字符串里有 ⚠️ 🍅 等。**修复**：渲染代码时统一 `EMOJI.sub('', line)`（源文件不动）。

11. **图片路径不可移植**
    源里写绝对路径会绑定机器。**修复**：源里用 `图：images:<相对路径>`，`IMG_ROOT` 由环境变量覆盖。

12. **图片与页面对不上**
    先按需求清单里的"出处 = PPT 第 N 页"**精确匹配**（用描述文本逐字比对）；教案补充的配图没有页码，用**关键词重叠**匹配到最相关的一页。

13. **代码页标题层级混乱**
    标题里既有时序号又有文件名。**修复**：标题取脚本头注释的"功能描述"，**不出现第几步**；环节与文件名放**页脚**（微软雅黑 10pt 灰）。

14. **连续步骤重复贴同一份代码**
    `app.py` 在多个步骤里一字不变，却贴了 8 遍。
    **修复**：与本讲前面任一脚本**相似度 ≥0.85 且改动 ≤6 行** → 不再贴，改一页说明"与《xx》基本相同（仅新增 N 行）"。MP3 因此从 553 张降到 475 张。

15. **同环节多脚本时页码重复**
    `1/4…4/4` 之后又从 `1/2` 开始。**修复**：同一锚点下的所有脚本页**连续编号**。

## 四、定下来的规则与阈值（可直接复用）

| 项 | 值 |
| --- | --- |
| 代码每页行数 | **≤20**，按逻辑断点分页 |
| 代码字号 | 按行数 12 / 11 / 10 pt 自动 |
| 重复代码豁免 | 相似度 **≥0.85** 且改动 **≤6 行** → 说明页 |
| 复习答案长度 | ≤200 字（≈4 行），超限才精简，且括号安全 |
| 复习页字号 | 12pt；问题静态、答案段落级淡入 |
| 页脚 | 微软雅黑 10pt、灰 `#8A939E`、右对齐、y=5.2 英寸 |
| 正文 | 微软雅黑；纯文字页宽 22cm；有图时图 10cm / 文 10cm |
| 配色 | 正文 `#222A35`、副标题蓝 `#1D4ED8`、灰 `#8A939E` |
| 动画 | 只加"解答性内容"；封面/内容页默认静态 |
| 禁止 | emoji、面向老师的元叙述、"代码清单"独立页、行首标点 |

## 五、可复用的"改版节奏"

1. **一讲一审**：先通读，列出问题清单（编号），用户挑哪几条再改，**不一次全改**。
2. 每讲改完**立即重生成 + 校验**（页码、emoji、占位、节数）。
3. 全部改完做**一次全量体检**（跨讲一致性：引脚、间隔、术语、重复表）。
4. 新增内容（代码页/图片/复习页）都走**"生成器 + 幂等重跑"**，不要手工在 24 个文件里复制粘贴。
5. 工具与规范**抽成 Skill**（`course-ppt`），项目里只留内容。

## 六、一页速查：最容易忘的三件事

- **改源之后一定要 `build_ppt.py`**，`.pptx` 是生成物，别直接改。
- **`place_codes.py` / `rebuild_review.py` 幂等**，但 `inject_codes.py` 只是首次注入（有保护）。
- **`.pptx` 别开在 PowerPoint 里生成**，否则得到 `_fixed.pptx`。
