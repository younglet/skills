# course-ppt 使用说明（可移植版）

> 一套把 **Markdown 讲稿编译成"教材式"PPT** 的规范 + 工具，沉淀自 MicroPython MP2 / MP3 课件的完整改版实战。
> 把这个文件夹整个拷到别的项目根目录即可继续用。
> **关键一步**：把 `tools/*.py` 复制到项目根目录（与 `模板.pptx` 同层）再运行——脚本靠自身位置定位项目。

---

## 一、包里有什么

```
course-ppt/
├── SKILL.md              技能入口：规则总览 + 工具表（给 AI 看的）
├── 使用说明.md            本文件：怎么在新项目里跑起来
├── 实战经验.md            踩过的坑、关键决策与阈值（强烈建议先读）
├── reference/
│   └── 规范细则.md        完整写作/排版/代码/流程规范
└── tools/
    ├── build_ppt.py           md → .pptx（分节、表格、图片、动画、页脚）
    ├── inject_codes.py        首次注入：复习 / 代码回顾 / 任务代码
    ├── place_codes.py         代码贴到对应环节 + 20 行逻辑分页 + 去顶部注释
    │                          + 重复代码改"说明页" + 页脚（环节｜文件）
    ├── rebuild_review.py      按教案「复习环节」重建复习页（问答成对 + 答案动画）
    ├── extract_image_needs.py 生成配图需求清单（描述/画面细节/关键词/功能/出处）
    └── attach_images.py       把图片按"出处"绑定回 PPT 源
```

## 二、新项目的目录约定

```
<项目根>/
├── 模板.pptx                 # 16:9 母版；版式名：1_自定义版式(封面) / 3_自定义版式(内容)
├── course-ppt/               # 这个包
├── <课程>/PPTs/MPx_XX_*.md   # ★ PPT 源（唯一手改对象）
├── <课程>/source_codes/…     # 每讲配套代码（贴进 PPT 的就是这些）
├── <课程>/lesson_plans/…     # 教案（复习页的问答来源）
└── images/                   # 生成好的图片（MPx_XX/MPx_XX_NN_slug.png）
```

> `build_ppt.py` 里 `HERE` 自动取脚本所在目录，所以**把它和 `模板.pptx` 放在同一层**最省事。

## 三、要改的配置（6 个脚本顶部）

| 脚本 | 常量 | 说明 |
| --- | --- | --- |
| `build_ppt.py` | `TPL` | 模板路径（默认同目录 `模板.pptx`） |
| | `IMG_ROOT` | 图片根目录（默认 `../images`，可用环境变量 `COURSE_IMG_ROOT` 覆盖） |
| | `IMG_ROOT`/`FULL_L` 等 | 版面尺寸（宽 22cm、图 10cm 等） |
| `inject_codes.py` | `PROJ`、`DIRS`、`REVIEW` | 项目路径、课程→代码目录映射、代码回顾取哪个脚本 |
| `place_codes.py` | `ROOT`、`DIRS`、`M` | 项目路径、目录映射、**锚点页子串 → 脚本列表**（决定代码贴在哪个环节旁） |
| | `SIM` / `ADD_MAX` | 重复代码判定阈值（默认 0.85 / 6 行） |
| `rebuild_review.py` | `PROJ`、`Q_LIMIT/A_LIMIT/CAP` | 项目路径、问答字数上限与每页行数 |
| `extract_image_needs.py` | `PROJ`、`OUT` | 项目路径、配图清单输出目录 |
| `attach_images.py` | `PROJ`、`IMG` | 项目路径、图片根目录 |

依赖：`python -m pip install python-pptx jieba pillow`

## 四、标准流程（按顺序）

```bash
# 0) 写好 / 改好 <课程>/PPTs/MPx_XX_*.md（每页 ### 第 N 页 · 标题）

# 1) （仅首次）把 source_codes 的代码注入 PPT 源：复习 / 代码回顾 / 任务代码
python inject_codes.py MP2          # 或 MP3；有防重复保护，跑过会跳过

# 2) 把代码页贴到对应环节旁；20 行逻辑分页、去顶部注释、重复代码改说明页、加页脚
python place_codes.py MP2

# 3) 按教案「复习环节」重建复习页（问答成对，答案逐条动画）
python rebuild_review.py

# 4) 生成配图需求清单（描述 / 画面细节 / 关键词 / 功能 / 出处）
python extract_image_needs.py

# 5) 图片做好后，绑定回 PPT 源（按"出处"精确匹配，幂等）
python attach_images.py

# 6) 生成 PPT
python build_ppt.py
```

> 顺序要点：**改源 → place/rebuild → build**。
> `place_codes.py` 与 `rebuild_review.py` 都是**幂等**的（先删旧的再重建），可以反复跑。

## 五、PPT 源语法（生成脚本认这些标记）

| 写法 | 效果 |
| --- | --- |
| `### 第 N 页 · 标题` | 一页（页号必须连续） |
| `- 问：…` | 提问（加粗、静态） |
| `- 答：…` | 正文（显示时去掉"答："） |
| `- 图：images:<相对路径> \| <描述>` | 插入真实图片（缺图则退回文字占位） |
| `页脚：<环节> ｜ <文件>` | 幻灯片底部**微软雅黑 10pt 灰色**右对齐小字 |
| `<<gap>>` | 空行间隔（复习页问答分组用） |
| `### 小标题` | 页内子标题（蓝色加粗） |
| `\| … \|` 表格 | 转成 PPT 真表格 |
| ` ``` ` 代码块 | Consolas 等宽框，自动 9~12pt、**每页 ≤20 行** |

## 六、生成后自查清单

- [ ] 幻灯片张数、**节数 = 课程讲数**（`p14:section` 数量）
- [ ] 页码连续、无 `第 _ 页`
- [ ] 无 emoji、无 `【图片占位】` 残留
- [ ] 图片数量 = `images/` 里的张数
- [ ] 代码块最大 20 行
- [ ] 复习页：问答成对 + 答案带 `<p:pRg>` 段落动画
- [ ] 代码页页脚存在且指向正确环节

## 七、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 生成出 `MPx_PPT_fixed.pptx` | `.pptx` 正开在 PowerPoint 里被锁；关掉后覆盖回去 |
| 节数不对（比如翻倍） | `PPTs/` 目录里混入了别的课程文件；`build_ppt.py` 是按 `MPx_*.md` 的 glob 数量分节的 |
| 图片没插进去 | `IMG_ROOT` 指错，或源里的 `images:` 相对路径与实际文件对不上 |
| 复习页答案跑到页尾 | 复习页必须保持原序（`build_ppt.py` 对 `复习` 页有特殊分支：全静态保序 → 再改成段落动画） |
| 页脚与代码重叠 | 代码 20 行 × 11pt 约到 5.0 英寸；页脚固定在 5.2 英寸。再加行请先减小字号或分页 |
| 关键词提取很差 | 没装 `jieba` |
